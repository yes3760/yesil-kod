HOW IT WORKS
1

FindBul

Static analysis walks the code’s syntax tree and flags thirty energy-wasting patterns, line by line.

2

FixDüzelt

The engine rewrites six of them itself: batched query, set lookup, loop hoisting, caching, min/max instead of sorting, removing needless copies. Comments and formatting stay untouched.

3

VerifyDoğrula

Both versions are run. If the outputs are not identical, the fix is rejected.

4

MeasureÖlç

CPU energy counters are read; the energy for the same work is converted to carbon.
