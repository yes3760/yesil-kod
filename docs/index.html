Yazılımın enerjisini ölçer, israfı düzeltir, kazancı kanıtlar.

Measures software energy, fixes the waste, proves the gain.

Yeşil Kod, Python kodunda enerji israf eden kalıpları bulur, kodu kendisi yeniden yazar, iki sürümün birebir aynı sonucu verdiğini doğrular ve harcanan enerjiyi ölçüp karbona çevirir.

Yeşil Kod (“Green Code”) finds energy-wasting patterns in Python, rewrites the code itself, verifies both versions return exactly the same result, then measures the energy and converts it to carbon.

Nasıl çalışıyorHow it works

Ölçülmeyen şey optimize edilemez. Yeşil Kod dört adımda çalışır.

You cannot optimise what you do not measure. Yeşil Kod works in four steps.

1

BulFind

Statik analiz kodun sözdizimi ağacını tarar, enerji israf eden dokuz kalıbı satır satır işaretler.

Static analysis walks the syntax tree and flags nine energy-wasting patterns, line by line.

2

DüzeltFix

Motor dört kalıbı kendisi yeniden yazar: toplu sorgu, kümeyle arama, döngü dışına taşıma, önbellek. Yorumlara ve biçime dokunmaz.

The engine rewrites four of them itself: batched query, set lookup, loop hoisting, caching. Comments and formatting stay untouched.

3

DoğrulaVerify

İki sürüm de çalıştırılır. Çıktılar birebir aynı değilse düzeltme reddedilir.

Both versions are run. If the outputs are not identical, the fix is rejected.

4

ÖlçMeasure

İşlemcinin enerji sayaçları okunur; aynı iş için harcanan enerji karşılaştırılır ve karbona çevrilir.

CPU energy counters are read; the energy for the same work is compared and converted to carbon.

Karbon hesabıCarbon accounting

SCI = (E × I + M) / R
  • E: ölçülen enerji. Linux’ta Intel/AMD RAPL sayaçları, Mac’te Apple’ın işlemci güç verisi (powermetrics), izin yoksa işlemci süresi × çekirdek gücü.
  • I: Türkiye şebekesi, 341 gCO₂e/kWh (Ağustos 2025–Temmuz 2026).
  • M: donanımın gömülü emisyonu; sonraki aşamada eklenecek.
  • R: istek başına.
  • E: measured energy. Intel/AMD RAPL counters on Linux, Apple’s CPU power data (powermetrics) on Mac, CPU time × per-core power without permission.
  • I: Türkiye grid, 341 gCO₂e/kWh (Aug 2025–Jul 2026).
  • M: embodied hardware emissions; planned for the next phase.
  • R: per request.

Dürüst sınırlarHonest limits

  • Yalnızca işlemci enerjisi ölçülür; bellek, ağ ve soğutma dahil değildir. Gösterilen kazanç alt sınırdır.
  • Tahmini modda mutlak değerlerden çok oranlar güvenilirdir.
  • Düzeltilmiş koddaki önbellekler her istekten önce temizlenir; kazanç önceki ölçümden kalmaz.
  • Motor şimdilik Python içindir.
  • Only CPU energy is measured; memory, network and cooling are excluded. The gain shown is a lower bound.
  • In estimated mode, ratios are more reliable than absolute values.
  • Caches in the fixed code are cleared before every request, so gains never come from earlier runs.
  • The engine currently supports Python only.
